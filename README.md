# Практическая работа №1

## Тема

HTML и базовая CSS-разметка.
Семантическая структура страницы.

## Что реализовано

- семантическая структура страницы;
- навигация по разделам;
- 6 карточек;
- таблица;
- форма регистрации;
- HTML-валидация формы;
- изображения из dataset;
- Flexbox;
- адаптивная верстка.

## Использованные данные

Использованы файлы:

- data/content.csv
- data/navigation.json
- images/logo.svg
- images/cover.svg

Значения из CSV и JSON были перенесены
в HTML вручную.

Исходные файлы не изменялись.

## Запуск проекта

1. Скачать или клонировать репозиторий.
2. Открыть файл index.html в браузере.

Дополнительные библиотеки не требуются.

## Проверка

Проверены:

- ссылки навигации;
- адаптивность страницы;
- обязательные поля формы;
- неверный формат email;
- минимальная длина имени и комментария;
- числовое ограничение поля опыта.
